# Проект «Stellar Burgers»

> Учебный проект, выполненный в рамках курса «Фронтенд-разработчик» от Яндекс Практикума по разработке React-приложения с маршрутизацией, глобальным состоянием, авторизацией и автоматическими тестами.

### Задача проекта:
- Настроить маршруты и подключить готовые страницы к данным сервера.
- Организовать глобальное состояние приложения через Redux Toolkit.
- Реализовать авторизацию и ограничить доступ к личному кабинету.
- Добавить логику конструктора, оформления заказа и работы с профилем.
- Написать модульные тесты редьюсеров и браузерные тесты пользовательских сценариев.

## Описание проекта
**Stellar Burgers** — веб-приложение космической бургерной, где можно собрать собственный бургер и оформить заказ. Пользователям доступны каталог ингредиентов, общая лента заказов и личный кабинет с редактированием профиля и историей покупок.

Страницы, UI-компоненты и функции запросов к API предоставлены в заготовке. Моя работа — подключение данных, реализация логики приложения, маршрутизации, авторизации и тестов.

## Реализовала:
- Настроила маршруты конструктора, ленты заказов, профиля и форм авторизации через React Router.
- Добавила открытие деталей ингредиентов и заказов в модальных окнах с поддержкой отдельных страниц при прямом переходе по ссылке.
- Организовала Redux-хранилище со слайсами ингредиентов, конструктора, пользователя, ленты и заказов.
- Подключила готовые API-функции через `createAsyncThunk`, добавила состояния загрузки и ошибок.
- Реализовала добавление и удаление ингредиентов, выбор булки и расчёт стоимости бургера.
- Настроила оформление заказа для авторизованных пользователей, отображение его номера и очистку конструктора.
- Подключила регистрацию, вход, выход, восстановление пароля и проверку авторизации для приватных страниц.
- Реализовала редактирование профиля с сохранением изменений и отменой введённых данных.
- Подключила общую ленту заказов, статистику и персональную историю заказов.

### Тестирование
- Написала тесты Jest для редьюсеров ингредиентов и конструктора: начального состояния, изменения данных и обработки асинхронных действий.
- Добавила тесты Playwright для добавления ингредиентов и открытия модального окна с их описанием.
- Проверила закрытие модального окна крестиком и кликом на фон.
- Покрыла сценарий оформления заказа: отображение номера, очистку конструктора и закрытие подтверждения.
- Настроила подмену ответов API через HAR-файлы и использование тестовых токенов авторизации.
- Настроила запуск браузерных тестов в Chromium, Firefox и WebKit.

## Результат:
- Научилась объединять готовые React-компоненты в приложение с общим состоянием и навигацией.
- Закрепила работу с Redux Toolkit: слайсами, селекторами и асинхронными действиями.
- Освоила защищённые маршруты и отображение модальных окон с сохранением фоновой страницы.
- Получила опыт реализации авторизации и подключения пользовательских данных к интерфейсу.
- Научилась проверять редьюсеры отдельно от компонентов и воспроизводить пользовательские сценарии в браузерных тестах.
- Освоила подмену сетевых ответов, чтобы тесты использовали заранее подготовленные данные.

## Запуск

1. В каталоге проекта установите зависимости:

```bash
npm ci
```

2. Запустите приложение:

```bash
npm start
```

### Перед первым запуском браузерных тестов

Установите Playwright:

```bash
npx playwright install
```

## Полезные команды

| Команда | Назначение |
| --- | --- |
| `npm start` | запуск сервера разработки |
| `npx webpack --mode=production` | сборка приложения в каталог `dist` |
| `npm test` | запуск модульных тестов Jest |
| `npm run test:e2e` | запуск браузерных тестов Playwright |
| `npx playwright show-report` | просмотр отчёта Playwright |
| `npm run storybook` | запуск Storybook |
| `npm run lint` | проверка кода через ESLint |
| `npm run format` | форматирование исходных файлов |
